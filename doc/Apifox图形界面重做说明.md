## 2. 操作步骤（全部在 GUI 内完成）

1. **新建项目**：首页右上角 `+ 新建项目` → 选"以可视化界面维护接口" → 项目名 → 创建。
2. **导入接口**：项目设置 → 导入数据 → `.har 文件` → 选 `doc/admin-api.har` → 关闭"过滤静态资源" →
   预览 12 条记录 → 导入到"默认模块" → **得到 12 个接口**（含 2 个 `/api/user/login`、2 个 `/api/admin/dashboard/index`）。
3. **配环境**：右上角环境下拉 → 管理环境 → 测试环境 → 前置 URL `http://127.0.0.1:8065` → 保存。
4. **建场景**：自动化测试 → 场景用例 → 逐个新建三个场景 → 在场景内 `+ 添加步骤` → `从接口导入` →
   勾选该场景需要的接口 → 添加（一次可勾多个，步骤按接口列表顺序生成）。
5. **运行**：场景详情页右侧运行设置 → 运行环境"测试环境" → 点底部运行按钮。

## 4. 图形界面里踩到的坑

1. **「+ 添加步骤」单击即弹出菜单**，不需要双击。菜单是网页内的浮层：一旦焦点切走（例如被别的窗口抢焦点），
   浮层仍显示但**不再接受点击**，点击会穿透到下层页面。所以"开菜单 → 点菜单项"必须在同一次鼠标注入脚本里完成。
2. **菜单弹出位置不固定**：步骤列表为空时菜单居中弹出（左侧 x≈606），已有步骤时贴着按钮向右上弹出（x≈950），
   点错位置会穿透到左侧接口树，误开接口详情页。定位前先截一张图确认坐标。
3. **Apifox 2.8.53 的自动化场景不回写登录 Cookie**：登录步骤返回 200、业务码 `code:1`，但
   `Set-Cookie: JSESSIONID=...` 没有进入场景内后续步骤的 Cookie 罐，管理端接口仍返回
   `{"code":401,"message":"用户未登录"}`，触发"校验响应（契约测试）"的结构比对失败。
   处理：项目设置 → 功能设置 → 响应校验设置 → 关闭「"测试步骤"里的校验响应」，
   GUI 侧只验证请求链路与响应可达；**业务级断言以 CLI 集合为准**。
4. **主窗口最小宽度大于 1536 屏宽**，右侧运行设置面板被裁；用 `MoveWindow` 移动窗口可临时露出，
   但会让整体布局重排，操作完要还原。
5. 导入的接口各自带一份请求头快照（`Content-Type`/`Accept`/`User-Agent`/`Origin`/`Referer`），
   与 HAR 记录一致；`Cookie` 不在其中，说明 401 来自 Cookie 罐而不是请求头快照。
